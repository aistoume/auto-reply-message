# 嘴替 · Aplomb

**难回的消息，替你说出口。**

站在聊天界面上点一下悬浮球，选一个语气，AI 读懂这一屏在说什么，替你写出能直接发出去的那句话。

<img width="240" alt="Aplomb" src="app/src/main/res/mipmap-xxxhdpi/ic_launcher.png">

---

## 它解决什么

老板画饼、甲方压价、亲戚催婚、前任试探——这些消息难的从来不是打字，是**想不出怎么说才既守住底线又不撕破脸**。

嘴替给的不只是一句回复，而是四件事：

| | |
|---|---|
| **潜台词翻译** | 对方这句话真正想干什么：施压 / 试探 / 甩锅 / 卖惨 / 铺垫要求 |
| **误读风险** | 截图信息不足或有歧义时明说，不硬猜 |
| **分档回复** | 按你选的语气写出可直接发送的正文 |
| **发送建议** | 这句发出去会怎样，你还得自己确认什么 |

方法论来自 [zuiti-skill](https://github.com/SilentFleetKK/zuiti-skill) 与 [zuiti-jiafang](https://github.com/SilentFleetKK/zuiti-jiafang)（MIT），按手机场景重排——站在对话框前的人，先要的是「现在发什么」。

## 怎么用

1. 点悬浮球 → 自动截取当前聊天
2. 情绪轮盘展开 → 选一档
3. 回复卡出现：潜台词在上，正文在中，建议在下
4. 点「填入输入框」→ 内容进入聊天输入框
5. **你自己检查，你自己按发送**

## 两个设计选择

**语言分工.** 回复正文跟着**对方**的语言走（对方发英文就回英文，日文回日文）；潜台词和建议永远用**你的**语言写给你看。你读母语，对方读母语。

**只填不发.** 嘴替不替你按发送键，也不监听通知、不装无障碍服务、不自动接管对话。AI 写的每一个字，发出去之前都经过你的眼睛——因为对面那个人以为在和你说话。

## 情绪档位

出厂四档，全部可改（emoji、名称、颜色、以及**给 AI 的说话方式**），最多 6 档：

| 档位 | 怎么说话 |
|---|---|
| 🙂 体面 | 保留关系、留有余地，对方容易接受 |
| 🪡 绵里藏针 | 把问题摆到明面上，守住底线，既不硬怼也不妥协 |
| 🔥 掀桌 | 讲清规则、不再退让，接受关系可能结束——仍然只讲事实 |
| 🧊 冷处理 | 先不表态、不接话茬，把决定权留在自己手里 |

出稿后回复卡底部可**直接换档重出**，不用退回轮盘重新截图。

## 分寸底线

写进 prompt、任何档位都适用：

- 不脏字、不人身攻击、不威胁、不造谣
- 最狠的档位也只讲事实和后果
- 不替你承诺钱、时间、法律责任——需要你定的写进「建议」，不写进正文
- 涉及家暴、自伤、人身安全的对话，正文保守，并提示走现实求助渠道

## 隐私

没有服务器。API key、设置、情绪档位只存在你手机上；截图和请求由你的手机**直连**你自己配置的 AI 提供方。不收集、不上传、无遥测、无广告。

支持 Anthropic Claude（读潜台词最准）、OpenAI GPT、Google Gemini（有免费额度）、OpenRouter（免费模型）。

## 构建

```bash
./gradlew :app:assembleDebug
```

Android 8.0+（minSdk 26）。首次使用需要三个权限：显示在其他应用上层、屏幕分享（每次会话一授权）、启用嘴替键盘（用于填入文字）。
